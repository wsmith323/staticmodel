# StaticModel Documentation

**StaticModel** provides a framework for modeling collections of complex
constants in Python.

Start with the user guide for the core API, primitive collection output, Django
model fields, and Django REST Framework serializer fields. The rationale page
keeps the longer explanation of the problems StaticModel is intended to solve.
